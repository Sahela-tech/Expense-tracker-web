# 💰 Expense Tracker Web Application

A lightweight, modern, and user-friendly Web-based **Expense Tracker** application designed to help users track their daily financial transactions effortlessly. Built with HTML5, CSS3, and JavaScript, leveraging browser LocalStorage for persistent data storage.

---

## 🌟 Features

- **Add Transactions:** Log daily expenses with title, amount, and category.
- **Categorization:** Classify expenses into predefined categories (Food, Bills, Transport, etc.).
- **Real-Time Total:** Dynamic total calculation updated instantly upon entry or deletion.
- **Persistent Data:** Expenses stay saved even after refreshing the page (via LocalStorage).
- **Responsive UI:** Clean and modern design adaptable across all screen sizes.
- **Delete Expense:** Quick deletion of individual transactions.

## 🚀 How to Run Locally

1. **Clone or Download** this repository.
2. Open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari).
3. No external dependencies or backend servers required!
